# Health Tracker v0.4 — Telegram Bot + Mini App + JSON

Бот и интерфейс Mini App в **одном Docker-контейнере**, PostgreSQL не нужен. Измерения, питание, тренировки и напоминания записываются отдельно для каждого пользователя в `/app/data/user_<telegram_id>.json`. Формат полностью совместим с v0.3, новые поля необязательны.

## Функции

- Главное меню бота с пошаговым вводом веса, давления, пульса, питания, тренировок и напоминаний. Отмена: `/cancel`. Для измерений доступно указание исторической даты.
- Mini App: пять разделов (Сегодня, Здоровье, Питание, Активность, Напоминания), график показателей, история, добавление и удаление записей, исторические даты измерений/питания/тренировок.
- Локальный каталог `products.json` с **40 демонстрационными усреднёнными позициями**, поиском и расчётом КБЖУ на вес порции. Данные **ориентировочные**, не являются проверенной базой производителя. Сырые и приготовленные продукты различаются; брендов и штрихкодов пока нет. Можно вводить свою позицию с данными на 100 г.
- Дневные напоминания продолжают отправляться через Telegram (при работающем боте). Часовой пояс `/timezone Europe/Moscow`.
- Экспорт личных данных: `/export`. Старые команды `/food`, `/workout`, `/chart`, `/pressure` и прочие сохранены.

## Быстрая установка

1. Создайте Telegram-бота в @BotFather, скопируйте токен.
2. Скопируйте `.env.example` в `.env` и задайте `BOT_TOKEN`.
3. Настройте **публичный HTTPS адрес** контейнера и переменную `WEBAPP_URL=https://<ваш-домен>/` (точный URL сайта Mini App). Платформа должна проксировать порт `8080` к HTTPS-домену.
4. `docker compose up -d --build` (на Bothost загрузите исходники и выберите сборку через Dockerfile; откройте HTTP-порт `8080` в настройках платформы).
5. Создайте persistent volume / bind mount для **`/app/data`**. Перед обновлением обязательно резервируйте папку и *не удаляйте её*. Без тома данные теряются при пересоздании контейнера.
6. Откройте бота в личном чате, выполните `/start`, затем `/app`. Веб-ссылка проверяется по `Telegram.WebApp.initData`; в обычном браузере без Telegram данные недоступны.

Для локальной разработки без HTTPS бот работает, а Mini App доступен только при опубликованном HTTPS. Мини-приложение появляется через кнопку `/app` после указания `WEBAPP_URL`.

## Конфигурация

```
BOT_TOKEN=...
DATA_DIR=/app/data
DEFAULT_TIMEZONE=Asia/Yekaterinburg
WEBAPP_URL=https://example.com/
PORT=8080
```

`products.json` — редактируемый каталог на 100 г: `id` (уникальный), `name`, `calories`, `protein`, `fat`, `carbs`. Изменения в каталоге влияют на новые записи, но не переписывают ранее сохранённые КБЖУ.

## Безопасность и ограничения

- Telegram Mini App API проверяет HMAC-SHA256 подпись `initData`, не доверяет переданному клиентом `user_id`, ограничивает возраст подписи 24 часами. **Не логируйте `initData`, не передавайте токен в HTML.**
- Данные о здоровье чувствительны. Нужны HTTPS, закрытые права на каталог `/app/data`, резервные копии, ограничение доступа к серверу и продуманная политика хранения/удаления. JSON в текущей версии **не зашифрован на диске**.
- Запускайте **ровно один экземпляр контейнера / один worker**. Синхронизация использует внутрипроцессные `asyncio.Lock`: несколько процессов могут вызвать потерю обновлений. Для расширения потребуется транзакционная БД.
- В текущем MVP напоминания ежедневные: без отметок о приёме и защиты от всех дублей после сбоя. Используются интервалы проверки 20 секунд, поэтому возможны задержки или пропуск минуты при остановке сервиса.
- У продукта ориентировочные значения; энергия тренировок вводится вручную и не является медицинским измерением. Дневная сводка основана только на внесённых записях.
- На публичном развёртывании рекомендуются ограничения частоты запросов к API и регулярные резервные копии.

## Проверки

`python -m compileall -q bot.py wizard.py miniapp_api.py runner.py`, `python -m json.tool products.json`.

## Архитектура

`runner.py` импортирует `bot` **один раз**, поэтому бот и API разделяют одни блокировки и функции атомарного сохранения. `bot.py` запускает aiogram polling, цикл напоминаний и uvicorn на порту `8080` в одном asyncio loop. `wizard.py` реализует пошаговые формы бота, `miniapp_api.py` — API и проверку подписи, `web/index.html` — интерфейс без внешних JS-фреймворков. При остановке приложения обрабатывается выход обоих сервисов.
